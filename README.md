 Zero-Trust Secure File Sharing System Using Hybrid Cryptography

 Project Overview

The Zero-Trust Secure File Sharing System Using Hybrid Cryptography is a cybersecurity mini project designed to provide secure file storage and sharing through advanced cryptographic techniques and zero-trust security principles.

The system uses AES-256-GCM symmetric encryption to encrypt files and RSA-OAEP asymmetric encryption to securely protect encryption keys. It ensures that only authenticated and authorized users can access shared files.

Unlike traditional file-sharing systems, this application follows the Zero-Trust security model, where every access request is verified based on user identity, permissions, and file ownership. It also provides access revocation, file integrity verification, and tamper-evident audit logging to improve data security and privacy.

 Objectives

- Protect confidential files using hybrid cryptography.
- Implement zero-trust authentication and authorization.
- Enable secure file sharing between authorized users.
- Prevent unauthorized file access and modification.
- Verify file integrity using cryptographic hashes.
- Maintain secure audit logs for file-related activities.

 Key Features

- AES-256-GCM file encryption and decryption.
- RSA-OAEP encryption key protection.
- Secure user authentication and authorization.
- Role-based access control.
- Secure file sharing with specific users.
- Dynamic access revocation.
- SHA-256 file integrity verification.
- Tamper-evident audit logging.
- Secure dashboard for file management.

 Expected Outcome

The project demonstrates how hybrid cryptography and zero-trust security can be combined to build a secure file-sharing application. It provides a practical implementation of confidentiality, integrity, authentication, and access control in modern cybersecurity systems.
